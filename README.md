# Aqua Care 1.0

Aqua Care is een local-first aquariumonderhoudsapp.

## Functies
- onderhoudsplanning met dynamische volgende datum
- filters en waterwissels
- voorraad en automatische boodschappenlijst
- logboek
- aquariumprofiel
- vissen per soort met mannetjes, vrouwtjes en jong/onbekend
- planten
- foto's
- lokale browsermeldingen
- PWA-installatie
- JSON back-up en herstel

## Data
Aquariumgegevens worden lokaal in de browser opgeslagen via localStorage en worden niet in deze repository opgeslagen.

## PWA
Voor installatie als PWA moet de app via HTTPS of localhost worden geopend. GitHub Pages is hiervoor geschikt.
